# Source Confidence

## Confidence labels

Use clear labels:

- `High`: confirmed by primary source, codebase evidence, or direct runtime observation.
- `Medium`: supported by credible secondary evidence or partial project evidence.
- `Low`: plausible but missing direct confirmation.
- `Unknown`: evidence was not found or sources conflict.

## Source priority

Prefer sources in this order when applicable:

1. Direct project code or runtime behavior.
2. Official documentation or source repository.
3. Package registry metadata and release notes.
4. Maintainer issue comments or discussions.
5. Community examples and articles.

## Reporting rule

State what was checked, what was found, what remains uncertain, and how uncertainty affects the decision.
