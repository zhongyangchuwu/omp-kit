# Codebase Research

## Procedure

1. Locate relevant files and symbols with targeted lookup.
2. Read the smallest complete sections that explain behavior.
3. Trace callers, data flow, configuration, and tests when they affect the decision.
4. Record observed conventions and contracts.
5. Identify gaps that require planning, implementation, review, or verification.

## Evidence to capture

- files and symbols inspected;
- existing patterns to reuse;
- public contracts and callsites;
- relevant tests and fixtures;
- configuration and runtime assumptions;
- risks and unknowns.

## Boundary rule

Research explains the current system and options. It does not edit code or rewrite the plan.
