# Verification Record

Use this shape for durable verification output:

```markdown
# Verification

## Claims Checked

## Evidence Observed

## Coverage

## Failed Checks

## Skipped Checks

## Untested Claims

## Result
```

## Result values

- `passed`
- `failed`
- `blocked`
- `partial`

## Record rule

A verification record must support the completion claim without relying on conversation memory.
