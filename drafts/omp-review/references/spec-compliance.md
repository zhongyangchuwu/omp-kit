# Spec Compliance Review

## Inputs

Use the available goal, context, plan, requirements, acceptance criteria, and verification expectations.

## Checks

- The implementation covers the stated goal.
- Each acceptance criterion has a corresponding implementation path.
- Non-goals remain untouched.
- Decisions and constraints are reflected in the change.
- Deviations are recorded and justified.
- New behavior has an appropriate verification path.

## Result

State whether the work is ready for verification, needs revision, or requires escalation.
