# Handoff Records

## Purpose

A handoff record lets a later session resume without replaying conversation history.

## Create handoff when

- work pauses before completion;
- a blocker requires external input;
- another agent or maintainer must continue;
- context is large enough that summary is safer than memory.

## HANDOFF.md structure

```markdown
# Handoff

## Resume Goal

## Current State

## Required Reading

## Completed Work

## Pending Work

## Blockers

## Verification So Far

## Next Action
```

## Handoff rule

Write the next action as an executable instruction. Include paths to required artifacts and files. Keep speculation out of handoff records.
