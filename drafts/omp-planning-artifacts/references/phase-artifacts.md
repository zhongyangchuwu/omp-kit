# Phase Artifact Contracts

## CONTEXT.md

Required sections:

- Goal
- Constraints
- Decisions
- Open Questions
- Verification Expectations

## RESEARCH.md

Required sections:

- Question
- Sources Checked
- Findings
- Tradeoffs
- Confidence

## PLAN.md

Required sections:

- Objective
- Scope
- Tasks
- Acceptance Criteria
- Verification
- Risks

## SUMMARY.md

Required sections:

- Completed Changes
- Files Changed
- Deviations
- Evidence
- Unresolved Risks

## REVIEW.md

Required sections:

- Scope Reviewed
- Findings
- Fixes Applied
- Waivers
- Remaining Risks

## VERIFICATION.md

Required sections:

- Claims Checked
- Evidence Observed
- Coverage
- Gaps
- Result

## CAPTURE.md

Required sections:

- Durable Docs Updated
- Planning Records Updated
- Learnings
- Ship Inputs

## Section rule

Use `None` for an intentionally empty required section. Do not omit required sections in full workflows.
HANDOFF.md is a pause artifact, not a phase artifact. It belongs in the phase directory so resume context stays with the work it pauses, but it records an interruption, not a phase completion.
