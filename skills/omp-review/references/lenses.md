# Review Lenses

Select lenses that match the changed surface.

## Correctness

Check behavior against stated goals, requirements, edge cases, and error paths.

## Maintainability

Check naming, abstractions, state transitions, error handling, tests, and unnecessary concepts.

## Security

Check trust boundaries, authentication, authorization, input validation, secrets, external writes, and dependency risk.

## Performance

Check repeated work, hot paths, unbounded loading, blocking I/O, lifecycle leaks, and unnecessary computation.

## API and contracts

Check public inputs, outputs, events, config, persisted data, compatibility, and migration impact.

## Operations

Check configuration, observability, rollback, deployment, and support procedures when runtime behavior changes.
