# Review Record

Use this shape for durable review output:

```markdown
# Review

## Scope Reviewed

## Inputs

## Findings

## Fixes Applied

## Waivers

## Remaining Risks

## Result
```

## Result values

- `ready-for-verification`
- `needs-revision`
- `escalated`

## Record rule

A review record should let a verifier understand what was checked, what changed because of review, and which risks remain accepted.
