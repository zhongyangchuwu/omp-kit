# User Acceptance Testing

## Use UAT when

- behavior is user-visible;
- the change affects workflow, UI, CLI, installation, configuration, or integration behavior;
- automated checks cannot prove the user outcome;
- the user requested acceptance validation.

## UAT record

```markdown
# UAT

## Scenario

## Preconditions

## Steps

## Expected Result

## Observed Result

## Evidence

## Result
```

## Result values

- `passed`
- `failed`
- `blocked`
- `partial`
