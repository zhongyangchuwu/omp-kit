# External Documentation Research

## Procedure

1. Resolve the exact library, framework, API, CLI, or service.
2. Prefer official docs, source repositories, release notes, and package metadata.
3. Check version-specific behavior when the project pins a version.
4. Compare examples against the project's language, runtime, and constraints.
5. Record source links or local reference paths when the output must be durable.

## Package selection checks

Check package purpose, maintenance status, registry identity, install name, version, license, and security signals when a new dependency is under consideration.

## Output rule

Recommend an option only when the evidence supports it. Mark unsupported options as assumptions or reject them.
