# Runtime Notes

This directory contains runtime-specific information. It is intentionally separated from portable Agent Skills authoring guidance.

Rules:

- Read these files only when the target runtime or tool is explicitly relevant.
- Do not treat these notes as portable requirements.
- Do not copy runtime-specific fields into a standard skill unless the user asks for that runtime.
- Keep standard guidance in the top-level references.

Runtime files:

- [claude.md](claude.md)
- [codex.md](codex.md)
- [npx-skills.md](npx-skills.md)
- [oh-my-pi.md](oh-my-pi.md)

Runtime-specific terms covered here include Claude Code, `$skill-creator`, `/skill:<name>`, `skill://`, `alwaysApply`, `globs`, and `npx skills`.
