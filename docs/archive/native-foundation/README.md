# Native-foundation phase archive

This directory preserves completed Phase 0/1 planning, configuration-ownership work, and detailed version-specific validation evidence for the `omp-native-foundation` transition.

Archived material is evidence and rationale, not active task routing. Settled principles are reflected in current `architecture.md`, `workflows.md`, repository policy, and the native plugin itself. Active unresolved work belongs in GitHub Issues indexed from `../../WORKING_STATE.md`.

Contents include:

- `OMP_NATIVE_CONFIG_AUDIT.md` — completed native configuration/ownership audit;
- `omp-roadmap.md` — completed Phase 0/1 roadmap and handoff history;
- `VALIDATION_PHASE1_2026-09-13.md` — detailed earlier native/runtime validation record, including OMP 18.1.18 experiments and their original scope limits.

Version-sensitive claims in archived files must be rechecked against the installed OMP version before being treated as present-day API/runtime behavior. Current validation summary lives in `../../VALIDATION.md`.
